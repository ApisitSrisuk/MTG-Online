# MTG Online

เว็บโต๊ะเล่น Magic: The Gathering กับเพื่อนแบบ real-time (2–4 คน) ใช้ได้ทั้ง 1v1 และ Commander
ข้อมูลและรูปการ์ดดึงจาก [Scryfall](https://scryfall.com) มีตัวช่วยกติกา (มานา, ลง Land เทิร์นละใบ, จังหวะการร่าย) และคำอธิบายการ์ดภาษาไทย

> โปรเจกต์แฟนเมดสำหรับเล่นส่วนตัว ไม่เกี่ยวข้องกับ Wizards of the Coast และห้ามนำไปหารายได้

## รัน

```bash
npm install
npm start
```

เปิด http://localhost:3000 ถ้าพอร์ต 3000 ไม่ว่าง ให้ตั้ง `PORT` เป็นพอร์ตอื่น เช่น PowerShell: `$env:PORT=3100; npm start`

## วิธีเล่น

1. ใส่ชื่อ แล้วเว้นรหัสห้องว่างไว้เพื่อสร้างห้องใหม่ จากนั้นกดปุ่ม **ห้อง XXXX 🔗** ด้านบนเพื่อคัดลอกลิงก์ส่งให้เพื่อน
2. เลือกเด็คแนะนำ หรือวาง decklist (MTG Arena / Moxfield / Archidekt) ใช้หัวข้อ `Commander` เพื่อแยกการ์ด Commander
3. เล่นได้เลย

| ทำอะไร | วิธี |
|---|---|
| ร่ายการ์ด | ดับเบิลคลิกหรือลากการ์ดที่ **เรืองแสง** ลงสนาม ระบบ tap land จ่ายมานาให้อัตโนมัติ |
| ผิดกติกา | ระบบจะเตือนพร้อมเหตุผล ถ้าการ์ดบอกว่าทำได้ ให้กด **ข้ามกติกา** (บันทึกใน log) |
| คำอธิบายภาษาไทย | ชี้เมาส์ที่การ์ด (แผงขวา) หรือคลิกขวา → 📖 คำอธิบายภาษาไทย |
| เริ่มเกม / จบเทิร์น | กด **🎲 สุ่มคนเริ่มเกม** กด **ขั้นต่อไป ➜** ไล่ phase จนถึง End แล้วกด **จบเทิร์น ➜** อีกฝ่ายจะ untap และจั่ว 1 ใบอัตโนมัติ |
| จั่ว / Scry / ค้นหา / Mulligan | คลิกกอง Library, คีย์ลัด `D` จั่ว, `N` ขั้นต่อไป |
| Tap / Untap | ดับเบิลคลิกการ์ดบนสนาม, กด `U` = untap ทั้งหมด |
| เมนูการ์ด (counter, คว่ำ, transform, ย้ายโซน) | คลิกขวาที่การ์ด |
| ดูสุสาน / Exile / Command | คลิกที่กองนั้น |

## เล่นกับเพื่อนต่างเครื่อง

- **วง LAN เดียวกัน:** ให้เพื่อนเปิด `http://<IP เครื่องคุณ>:3000`
- **ผ่านอินเทอร์เน็ต:** deploy ขึ้น Render หรือ Railway (Node service, start command `npm start`) หรือใช้ tunnel เช่น `cloudflared tunnel --url http://localhost:3000`

## โครงสร้าง

- `server.js`: Express + Socket.IO จัดการห้องและส่ง state
- `game.js`: สถานะเกมและคำสั่งทั้งหมด (server เป็นผู้ตัดสิน และกรองข้อมูลที่ซ่อนอยู่ก่อนส่งให้ผู้เล่นแต่ละคน)
- `public/rules.js`: กติกามานา/จังหวะร่าย ใช้ร่วมกันทั้ง server (ตรวจ) และหน้าเว็บ (ไฮไลต์การ์ดที่เล่นได้)
- `public/thai.js`: คำอธิบายการ์ดและคีย์เวิร์ดภาษาไทย
- `public/decks.js`: เด็คแนะนำ 4 เด็ค
- `scryfall.js`: อ่าน decklist และดึงข้อมูลการ์ด (มี cache)
- `public/`: หน้าเว็บ (HTML/CSS/JS ล้วน ไม่ต้อง build)
- `npm test`: ทดสอบการซ่อนข้อมูล, กติกามานา/จังหวะร่าย, ตัวอ่าน decklist และเด็คแนะนำ
